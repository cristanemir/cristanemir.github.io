# cristanemir — Portfolio

Portfolio personnel de Cristan Emir-Moungondo : parcours, compétences, projets GitHub et contact.

## Utilisation

Site statique en HTML, CSS et JavaScript. Aucun serveur applicatif, clé API ou dépendance à installer.
Ouvrir `index.html` dans un navigateur, ou utiliser `python3 -m http.server 8000`.

## Publication gratuite sur GitHub Pages

Dans le dépôt GitHub : **Settings → Pages → Build and deployment → Deploy from a branch**.
Choisir **main**, dossier **/ (root)**, puis **Save**.
Pour un dépôt nommé `cristanemir.github.io`, l’adresse attendue est https://cristanemir.github.io/.
La publication peut prendre quelques minutes.

## Modifier le contenu

- `index.html` : présentation, expérience, projets, compétences et e-mail.
- `style.css` : couleurs, typographie et mise en page responsive.
- `script.js` : filtres des projets et copie de l’e-mail.
- `favicon.svg` : icône du site.

La sélection de projets est éditoriale : elle ne nécessite pas de requête à l’API GitHub.
Les visuels des cartes sont des illustrations, pas des captures des applications.
Les polices Google Fonts sont facultatives : les polices système prennent le relais si elles sont indisponibles.
